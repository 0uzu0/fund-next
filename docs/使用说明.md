# LanFund 使用说明

本文档说明 **服务端** 与 **手机端（Android APP）** 的部署、配置与日常使用。

---

## 一、服务端使用说明

服务端提供 Web 前端页面与后端 API（端口 8311），支持 Docker 部署或源码运行。

### 1.1 部署方式概览

| 方式 | 适用场景 | 说明 |
|------|----------|------|
| **Docker 镜像（推荐）** | 生产 / 自建服务器 | 使用 CI 已构建好的镜像，拉取即用 |
| **本地 Docker 构建** | 无 CI 或需自定义构建 | 从源码在本地构建镜像后运行 |
| **源码运行** | 开发 / 调试 | 在本机用 Node 分别启动后端与前端 |

### 1.2 使用 Docker 镜像部署（推荐）

**前提**：已安装 Docker 与 Docker Compose。

1. 在项目根目录创建 `.env` 文件（可参考 `.env.example`）：

```env
# 镜像地址（替换为你的 GitHub 用户名与仓库名）
DOCKER_IMAGE=ghcr.io/你的用户名/fund-next:latest

# Session 密钥（必填，建议随机字符串或 UUID）
SESSION_SECRET=请替换为一串随机密钥

# 可选：时区，默认 Asia/Shanghai
TZ=Asia/Shanghai
```

2. 启动服务：

```bash
docker-compose up -d
```

3. 查看日志与状态：

```bash
docker-compose logs -f    # 查看日志
docker-compose ps         # 查看容器状态
```

4. 访问地址：

- **Web 前端**：http://服务器IP:8311（同端口，后端会托管前端静态资源）
- **健康检查**：http://服务器IP:8311/api/health

5. 停止服务：

```bash
docker-compose down
```

**说明**：数据与 Session 会持久化在 Docker 卷 `fund-data` 与目录 `backend/cache`，重启或重新 up 不会丢失。

### 1.3 本地 Docker 构建后运行

未使用 CI 或需要从源码构建镜像时：

```bash
docker-compose -f docker-compose.yml -f docker-compose.build.yml up -d --build
```

同样在 `.env` 中配置 `SESSION_SECRET` 等（若使用 build 配置，可能不需要 `DOCKER_IMAGE`，以 docker-compose.build.yml 为准）。访问方式同上。

### 1.4 源码运行（开发环境）

**前置**：Node.js >= 18。

1. 安装依赖：

```bash
npm run install:all
```

2. 配置后端 `backend/.env`：

```env
DB_PATH=./cache/fund_data.db
SESSION_SECRET=你的密钥
PORT=8311
CORS_ORIGIN=http://localhost:3000
```

3. 配置前端 `frontend/.env.local`（开发时指向本地后端）：

```env
NEXT_PUBLIC_API_URL=http://localhost:8311
```

4. 启动：

```bash
npm run dev
```

- 前端：http://localhost:3000  
- 后端 API：http://localhost:8311  

5. 首次访问：打开 http://localhost:3000，若未登录会跳转登录页。默认账号：`admin` / `admin`（请及时修改）。

### 1.5 服务端环境变量汇总

| 变量 | 说明 | 示例 |
|------|------|------|
| `PORT` | 服务端口 | `8311` |
| `SESSION_SECRET` | Session 加密密钥 | 随机字符串 |
| `DB_PATH` | SQLite 数据库路径 | `./cache/fund_data.db` |
| `CORS_ORIGIN` | 允许的 Web 来源（开发时） | `http://localhost:3000` |
| `TZ` | 时区（Docker 时常用） | `Asia/Shanghai` |

### 1.6 镜像构建与发布（维护者）

- **自动**：代码 push 到 `main`/`master` 后，CI 会构建并推送 `ghcr.io/<仓库>:latest`。
- **手动**：在 GitHub Actions 中选择「CI/CD」workflow，点击 Run workflow，可选填写镜像标签（如 `v1.0.0`）。

## 二、手机端使用说明（Android APP）

手机端通过 WebView 加载服务端提供的 Web 页面，需先保证服务端已部署并可访问。

### 2.1 获取与安装 APK

- **从 Release 下载**：在 GitHub 仓库的 Releases 中下载 `lanfund-xxx.apk`，传到手机后安装。  
- **本地构建**：在项目 `mobile` 目录执行 EAS 或本地构建，得到 APK 后安装。

安装时若系统提示“未知来源”，需在系统设置中允许来自该来源的应用安装。

### 2.2 首次打开与配置服务器

1. 首次打开 APP 会进入 **设置** 页（未配置过服务器时）。
2. 在「服务器地址」中填写 LanFund 服务端地址，例如：
   - 局域网：`http://192.168.1.100:8311`（改为你实际的后端 IP 和端口）
   - 公网：`https://你的域名:8311` 或 `http://公网IP:8311`
3. 点击 **「测试连接」** 确认能连上后再点击 **「保存」**。
4. 保存后会自动进入主界面（WebView 加载 Web 端）。

**注意**：手机与服务器需网络互通（同一 WiFi 或手机能访问到服务器公网地址）；若后端使用 HTTPS，请填 `https://` 地址。

### 2.3 登录与使用

- 主界面加载的是与电脑版一致的 Web 页面。若未登录，会跳转到登录页。
- 使用与服务端一致的账号密码登录（如默认 `admin` / `admin`），登录状态会通过 Cookie 保持。
- 功能与 Web 端一致：持仓、持仓记录、市场行情、市场指数、贵金属、行业板块等，均通过底部导航或页面内导航切换。

### 2.4 底部导航栏

| 入口 | 对应页面 | 说明 |
|------|----------|------|
| 持仓 | 持仓基金 | 查看与操作持仓、估值等 |
| 记录 | 持仓记录 | 交易历史、撤销等 |
| 行情 | 市场行情 | 快讯、行情数据 |
| 设置 | APP 设置页 | 修改服务器地址、测试连接、清除本地数据等 |

底部导航与 Web 端侧边栏主要入口一致，便于在手机与电脑间切换使用。

### 2.5 设置页功能

- **服务器地址**：修改后端地址并保存，保存后主界面会使用新地址加载。
- **测试连接**：检查当前填写的地址是否可达（会请求服务端接口）。
- **重置**：将服务器地址输入框恢复为默认值（不保存，需再点保存才生效）。
- **清除本地数据**：清除 APP 内保存的服务器地址等，清除后再次打开会回到设置页重新配置。
- **关于**：查看应用名称、版本号、当前使用的服务器地址等。

### 2.6 其他操作

- **返回键**：在 Web 页面内按 Android 返回键会先退回上一页，无上一页时再退出 APP。
- **下拉刷新**：在 WebView 主区域下拉可刷新当前页面。
- **连接失败**：若主界面提示无法连接，可点「重试」或进入「设置」检查地址并重新测试连接、保存。

### 2.7 常见问题（手机端）

| 问题 | 处理建议 |
|------|----------|
| 无法连接服务器 | 确认手机与服务器网络互通；确认地址含 `http://` 或 `https://` 及端口（如 `:8311`）；在设置中「测试连接」排查。 |
| 登录后刷新又未登录 | 多为 Session 或 Cookie 问题，确认服务端 `SESSION_SECRET` 固定且未频繁重启导致 Session 丢失；使用 HTTPS 时更稳定。 |
| 页面空白或加载很慢 | 检查网络质量；首次加载需拉取完整前端资源，后续会使用缓存。 |
| 想换一台服务器 | 在 APP 设置中修改服务器地址并保存，即可切换到新服务端。 |

## 三、服务端与手机端配合关系

```
┌─────────────────────────────────────────────────────────────┐
│                     LanFund 服务端                           │
│  （Docker 或源码运行，端口 8311，提供 Web + API）              │
└─────────────────────────────────────────────────────────────┘
         │                                    │
         │ 同一地址（如 http://IP:8311）        │
         ▼                                    ▼
┌─────────────────────┐            ┌─────────────────────┐
│  电脑浏览器          │            │  Android APP        │
│  访问 http://IP:8311 │            │  设置中填同一地址    │
│  登录后使用全部功能   │            │  登录后使用全部功能  │
└─────────────────────┘            └─────────────────────┘
```

- 服务端只需部署一次，浏览器与 APP **共用同一套后端与数据**。
- 修改服务器地址、换设备或重装 APP 时，在手机端设置中重新填写并保存即可。
